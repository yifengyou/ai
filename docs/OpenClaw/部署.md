# 部署

> 本文整理自 OpenClaw 官方 [Install](https://docs.openclaw.ai/install) 与 [Getting started](https://docs.openclaw.ai/start/getting-started) 文档。

## 系统要求

*   **Node.js**：24.16.0+（24.x）或 26.1.0+；推荐 Node 26，强烈建议 24.22.1+ / 26.12.1+（含安全修复）。用 `node --version` 检查。
    *   安装脚本在缺失时会自动在 macOS 上装 Node 26、Linux 上装 Node 24 LTS。
    *   需手动安装见 [Node setup](https://docs.openclaw.ai/install/node)。
*   **操作系统**：macOS、Linux、Windows。
    *   Windows 推荐[原生 Windows Hub 应用](https://docs.openclaw.ai/platforms/windows)；也支持 PowerShell CLI 安装器与 WSL2 网关。
*   **AI 访问**：一个已登录的 Claude Code / Codex CLI，或某个模型提供者的 API key——onboarding 可复用它。
*   从源码构建才需要 `pnpm`。

## 安装

### 一键脚本（推荐，最快）

```bash
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash

# Windows (PowerShell)
iwr -useb https://openclaw.ai/install.ps1 | iex
```

安装完会自动启动引导式 onboarding。若只想安装不跑 onboarding：

```bash
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --no-onboard
```

### 一条命令试用（不持久安装）

```bash
npx openclaw@latest
```

新装时选 **Quick start** 即可：OpenClaw 自动发现已有的 Claude Code / Codex 登录或 API key，用一次真实 completion 验证，保存配置并打开 Web 仪表盘。网关在该终端前台运行直到 `Ctrl+C`，配置仍保留。

### npm / pnpm / bun

已自行管理 Node 时：

```bash
# npm 12 或 11.16+
npm install -g openclaw@latest --allow-scripts=openclaw
openclaw onboard --install-daemon

# npm 11.15 及更早不带 --allow-scripts 选项
npm install -g openclaw@latest
```

> npm 12 默认拦截未批准的生命周期脚本，需 `--allow-scripts=openclaw` 显式放行 OpenClaw 的 `preinstall`/`postinstall`。

```bash
# pnpm（全局安装不支持 approve-builds -g，需在 add 时带上）
pnpm add -g --allow-build=openclaw openclaw@latest
openclaw onboard --install-daemon

# bun
bun add -g --trust openclaw@latest
bun run --bun openclaw onboard --install-daemon --daemon-runtime bun
```

### 本地前缀安装（不依赖系统 Node）

把 OpenClaw 和 Node 一起放在 `~/.openclaw` 下：

```bash
curl -fsSL https://openclaw.ai/install-cli.sh | bash
```

### 从源码构建

```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
corepack enable
pnpm install && pnpm build && pnpm ui:build
pnpm add --global "openclaw@link:$PWD"
openclaw onboard --install-daemon
```

> 纯运行时打包用 `pnpm build:runtime`（不含类型声明）；开发/打包用 `pnpm build`。Corepack 会按 `package.json` 选定 pnpm 版本（当前 pnpm 12）。

### 桌面应用

*   **Windows（推荐）**：原生 [Windows Hub](https://docs.openclaw.ai/platforms/windows) 签名安装器：
    *   [OpenClawCompanion-Setup-x64.exe](https://github.com/openclaw/openclaw-windows-node/releases/latest/download/OpenClawCompanion-Setup-x64.exe)
    *   [OpenClawCompanion-Setup-arm64.exe](https://github.com/openclaw/openclaw-windows-node/releases/latest/download/OpenClawCompanion-Setup-arm64.exe)
*   **macOS**：菜单栏应用，从 [GitHub releases](https://github.com/openclaw/openclaw/releases) 下载 `OpenClaw-<version>.dmg`（优先）或 `.zip`，安装后启动 **OpenClaw.app**。

两种桌面应用都能在首次设置时配置本地网关，或连接已有的远程网关。

### 容器与包管理器

支持 Docker、Podman、Nix、Ansible、Kubernetes 等。详见：
* [Docker](https://docs.openclaw.ai/install/docker) · [Podman](https://docs.openclaw.ai/install/podman) · [Nix](https://docs.openclaw.ai/install/nix) · [Ansible](https://docs.openclaw.ai/install/ansible) · [Kubernetes](https://docs.openclaw.ai/install/kubernetes)

云部署见 [Linux server / VPS](https://docs.openclaw.ai/vps)（DigitalOcean、Hetzner、Hostinger、Fly.io、GCP、Azure、Railway、Oracle Cloud、树莓派等）、[Render](https://docs.openclaw.ai/install/render)、实验性 [Cloudflare Containers](https://docs.openclaw.ai/install/cloudflare)。

## 配置

OpenClaw 读取可选的 **JSON5** 配置文件 `~/.openclaw/openclaw.json`（支持注释与尾逗号）。文件缺失则用安全默认值。

> 配置路径必须是普通文件。OpenClaw 写配置时是原子替换（rename 到该路径），所以**不要用符号链接布局**配置文件；若配置在默认状态目录之外，用 `OPENCLAW_CONFIG_PATH` 直接指向真实文件。

### 编辑配置的四种方式

```bash
# 1) 交互式向导
openclaw onboard        # 完整 onboarding 流程
openclaw configure      # 配置向导

# 2) CLI 一行命令
openclaw config get agents.defaults.workspace
openclaw config set agents.defaults.userTimezone "Europe/Vienna"
openclaw config unset plugins.entries.brave.config.webSearch.apiKey

# 3) Control UI：打开 http://127.0.0.1:18789 用 Config 标签页
# 4) 直接编辑 ~/.openclaw/openclaw.json（网关会监视并热重载）
```

### 最小配置示例

```json5
// ~/.openclaw/openclaw.json
{
  agents: { defaults: { workspace: "~/.openclaw/workspace" } },
  channels: { whatsapp: { allowFrom: ["+15555550123"] } },
}
```

配置遵循"两桶规则"：根级兄弟字段承载基础设施与跨智能体默认值；`agents.defaults` 承载智能体循环行为；`agents.entries.<id>` 在 schema 支持处覆盖两者。

### 严格校验

⚠️ OpenClaw 只接受**完全匹配 schema** 的配置。未知键、错误类型或非法值会让网关**拒绝启动**：

*   启动失败时 `openclaw gateway run` 报错并以退出码 `78` 退出。
*   只有诊断命令可用（`openclaw doctor`、`openclaw logs`、`openclaw health`、`openclaw status`）。
*   运行 `openclaw doctor` 查看具体问题，`openclaw doctor --fix`（同 `--repair`，加 `--yes` 跳过提示）修复旧键。
*   根级唯一例外是 `$schema`（字符串）。
*   打印权威 JSON Schema：`openclaw config schema`。

热重载：无效的热更新会被**跳过**，运行时保留上次接受的配置。网关在每次成功启动后保留一份可信的"上次已知良好"副本，但只有 `openclaw doctor --fix` 会自动恢复它。

### 变量替换与密钥

*   配置值支持 `${VAR}` 环境变量替换。
*   密钥用 SecretRef（`env` / `file` / `exec` / `store`），见 [Environment variables](https://docs.openclaw.ai/gateway/configuration/environment-variables)。
*   相关环境变量：`OPENCLAW_HOME`（内部路径解析的 home 目录）、`OPENCLAW_STATE_DIR`（状态目录）、`OPENCLAW_CONFIG_PATH`（配置文件路径）。

## 运行

### 引导式上手（5 分钟）

```bash
# 1. 安装（见上）

# 2. 完成 onboarding（安装时已自动启动；之后可用 openclaw configure 重进）
#    选 Quick start 复用已检测到的 AI 访问；选 Custom setup 走完整引导

# 3. 把网关装成后台服务（前台运行时先 Ctrl+C 停掉）
openclaw gateway install
#    macOS: LaunchAgent；Linux/WSL2: systemd user unit；
#    原生 Windows: Scheduled Task（任务创建被拒则用 Startup 文件夹登录项）

# 4. 验证网关运行
openclaw gateway status     # 应监听 18789 端口

# 5. 打开仪表盘
openclaw dashboard          # 浏览器打开 Control UI

# 6. 发第一条消息：在 Control UI 聊天里发消息，应收到 AI 回复
```

想从手机聊天？最快接的是 [Telegram](https://docs.openclaw.ai/channels/telegram)（只需一个 bot token）。全部通道见 [Channels](https://docs.openclaw.ai/channels)。

### 常用 CLI

```bash
openclaw                   # TUI
openclaw gateway install   # 安装后台服务
openclaw gateway status    # 查看状态
openclaw gateway restart   # 重启
openclaw dashboard         # 打开 Web Control UI
openclaw configure         # 配置向导
openclaw doctor            # 诊断配置问题（--fix 修复）
openclaw triage            # 一键诊断：跑只读健康检查，生成脱敏提示并可选交给本机编码 agent
openclaw --version
```

### 验证安装

```bash
openclaw --version
openclaw doctor
openclaw gateway status
```

### 安装出问题

```bash
openclaw triage
```

它跑只读健康检查，写出脱敏的诊断提示，然后询问是否交给本机检测到的编码 agent（Claude Code / Codex CLI / 内置 OpenClaw agent），让 agent 带着诊断开局。在你选择 agent 前**任何东西都不会离开本机**，且密钥、token、原始聊天与日志被排除在外。想自己看结论则用 `openclaw doctor`。

### 卸载 / 更新 / 迁移 / 备份

*   [更新](https://docs.openclaw.ai/install/updating)：`openclaw update --channel stable|dev` 在 npm 与 git 安装间切换。
*   [迁移](https://docs.openclaw.ai/install/migrating)：搬到新机器。
*   [备份](https://docs.openclaw.ai/install/backups)：创建、校验、恢复状态归档。
*   [卸载](https://docs.openclaw.ai/install/uninstall)：完全移除。

### 自定义 Control UI 构建

维护本地化/定制仪表盘构建时，把静态资源放到 `$HOME/.openclaw/control-ui-custom`，然后：

```json
{ "gateway": { "controlUi": { "enabled": true, "root": "${HOME}/.openclaw/control-ui-custom" } } }
```

```bash
openclaw gateway restart
openclaw dashboard
```
